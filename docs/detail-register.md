# Full-detail geometry register · LAST LIGHT 3D

“Updated all areas” is not the acceptance criterion. Each reachable, visible family needs its own authored mesh or a justified shared assembly, editable source, collision/phase check, and first-person close-up review at representative and awkward placements. Check both phases where the mesh or lighting changes. A procedural shape is acceptable only when it has deliberately authored profiles, joints and proportions and passes the same review. Distant LOD, sky, light shafts and particles are separate from near geometry; don't substitute them for missing edges or forms. Log any camera-visible overlap or unsupported mount before closing the family.
